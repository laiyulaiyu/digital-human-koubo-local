# v0.1.0 验证范围

本版本保留原仓库基线 `5fa9b19f52fb8920c83567468fa30e8391b8c503` 的模板与剪辑脚本。真实样片验证仅覆盖B竖屏口播，不能据此宣称A/C/D/E或多语言已通过。

## 真实GPU生成及原模板渲染

环境：Windows，RTX 3060 12GB，32GB内存，ComfyUI 0.40.0，Remotion 4.0.408，H3源448×800。1080×1920为原模板的放大输出。

| 案例 | H3模式 | 源时长 | 总执行 | ASR文本相似度 |
|---|---|---:|---:|---:|
| 第一段普通口播 | 20步 | 9.417秒 | 35分10秒 | 93.3%（得/的同音识别差异） |
| 第二段普通口播 | Turbo8步 | 7.292秒 | 11分39秒 | 100% |
| 双手可见动作口播 | 普通20步+动作LoRA 0.5 | 6.583秒 | 23分21秒 | 100% |

两段合成16.661秒，动作版7.125秒。原assemble、align、voicefx及B模板均真实运行，逐文件完整解码和成片人声波形检查通过。查看原片及成片关键帧，修正过关键词与字幕拥挤。未把预期台词作为ASR提示。

动作版能看到右手展开、双手解释、头肩姿态变化和句尾回收。ASR四句起点约0.00、1.64、2.96、4.32秒；末尾实际为向前强调而非严格下拍，点头不明显。它是生成式语义配合，非逐字帧锁定。主观自然度、音色与动态口型仍需观看试听判断。

## 代码和可移植性

16项CPU契约及兼容检查覆盖清单、路径边界、失败续查记录、原云端任务数组格式、LoRA哈希/模型连线、手势顺序、字幕边界、原修音算法与音频解码依赖等；另验证bundled执行器和六份API工作流可在临时目录准备原生图结构，无需外部Skill。

隔离安装实际发现PyAV19移除了faster-whisper 1.2.1调用的metadata_errors参数，已将PyAV固定为18.0.0，并增加无需下载模型的本地WAV解码回归测试。不是只在预装环境中验证导入。

新增configure.py与doctor，使用配置文件相对路径。Python直接依赖在requirements.txt，发布验证所用完整依赖在requirements-lock.txt。B模板加入实际安装使用的package-lock.json。CI只运行CPU契约及编译检查，不采样GPU。

从独立目录准备出的H3+LoRA原生图，与已验证GPU样片的图在归一化任务ID后完全一致，不依赖外部Skill路径。随后用原已验证片段作明确标记的replay输入，重新运行实际ASR、裁尾、对齐、修音和原模板；ASR文本相似度100%。本轮安装检查没有重复GPU采样，也没有冒充新的全环境GPU验收。

## v0.1.0 之后的本地追加验证

环境仍为 Windows、RTX 3060 12GB、本机 ComfyUI 0.40.0 与 Remotion 4.0.408，H3 首帧源视频 448×800。新增样片为 960×540 或 540×960 的缩放预览；各样式仅验证以下短场景，不代表原参考工程的完整节目或全部素材已通过。各隔离工程复用已有 Node 依赖，并非独立安装验证。

- **A 解说**：原仓库已包含相邻 `finance-explainer` 引擎；用其原 `build_timeline.py`、真实口播和实测 ASR 时间轴完成两拍，验证全屏转小窗、步骤卡、字幕和音频。约 7.6 秒预览完整解码、关键帧检查通过，成片 ASR 与原稿一致。发现右侧大字越界，修复原引擎 `posStyle` 后重渲染验证。新增 `new_edit.py finance-explainer` 本地初始化入口。
- **C 发布解读**：12 秒原参考工程片段，验证开场、主播侧栏和内容区；缺失品牌图用标有 TEST 的占位素材。原开场在主播尚未出现时未播放首段语音，已修复并重渲染；离线 ASR 能在修复后识别开头台词，修复前在配乐上出现识别幻听。修复后开场及主播出现后的音频与源音轨偏移约 0.04 秒。原 MemT 节目文案仍需按新内容重写，此片仅供测试。
- **D 教程**：原参考工程开场及步骤界面＋主播小窗各渲染一个短片，界面为标明的虚构示意图；关键帧、完整解码和成片 ASR 检查通过。后续具体教程场景未逐一验证。
- **E 多主播多语言**：本地 Qwen 生成第二位虚构主播，H3 Turbo8 生成英文口播，与此前的中文主播片段接入原参考工程。约 11.8 秒预览验证两位主播切换、中英整句字幕和实际音轨；成片分段 ASR 均与原句一致，切换点抽帧与完整解码通过。修复语言片段开头字幕淡入过慢的问题。其他语种、同框及完整多场景节目仍待验证。
